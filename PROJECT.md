# Loki

## Overview

Loki is a translation management platform for managing YAML-based translation files through a web interface. It is primarily designed for Ruby on Rails I18n workflows, where translation keys and localized values are stored in YAML files.

The platform lets users import translation structure and default values from YAML files, add and edit translations in the UI, and export translations back to YAML.

## Core Features

- Multiple projects, each with its own set of locales
- Multi-user accounts with per-project access control
- Import of translation structure and default translations from YAML files
- Web-based editing of translations
- Export of translations back to YAML files
- Support for different translation value types: text, boolean, integer, float, array, and pluralization

## Target Use Case

Loki is intended for teams that manage application translations in YAML and need a simple web interface for collaborative translation editing without working directly with raw locale files.
